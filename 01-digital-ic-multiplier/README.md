# 6×6 CMOS Multiplier Design and Layout

Designed a 6×6 CMOS multiplier in a 180 nm process, comparing array and carry-save architectures and optimizing delay and area through mirror-adder cells, polarity alternation, inverter reduction, transistor sizing, pseudo-NMOS logic, and layout-aware design.

The folder contains the final report, project outline, and instructor-provided project description and report template. The original Cadence directory contains extensive generated simulation files; only a cleaned design export should be added after the schematic and layout database is curated.
