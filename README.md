# Xiaojun Zhou — Selected Course Projects

This repository collects selected coursework projects in microelectronics, digital design, computer architecture, signal processing, semiconductor fabrication, and TMD photodetectors.

Each project folder contains a short description, selected final artifacts, and—where appropriate—course requirement documents supplied by the instructor. Large generated simulator databases, caches, raw datasets, textbooks, reference answers, and unrelated teaching materials are intentionally excluded.
