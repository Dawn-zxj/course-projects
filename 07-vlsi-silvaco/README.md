# Silvaco CMOS Process Simulation

Built a Silvaco ATHENA process flow for CMOS fabrication and extracted process/device metrics including junction depth, oxide thickness, channel doping, gate-oxide thickness, and NMOS/PMOS threshold voltage.

The folder contains the project report and the course process/problem documents supplied for the laboratory. The clean Silvaco input and output files should be added after they are exported from the original project directory.
