# ARM/RISC-V Pipeline CPU Design

Implemented and simulated processor modules in Verilog, including datapath, control, register file, ALU, instruction and data memory, pipeline registers, hazard handling, and forwarding/bypassing logic.

The `source` directory contains the selected RTL, ARM source, simulation files, and upstream project license/README. Generated PDS, IP-core, synthesis, placement, and log files were excluded.
