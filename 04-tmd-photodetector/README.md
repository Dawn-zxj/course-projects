# TMD Photodetectors and Photodiode Heterojunctions

Fabricated and analyzed MoS₂/WS₂ heterojunction photodetectors, including substrate preparation, EBL pattern transfer, metal evaporation, 2D-material transfer, packaging, I–V testing, and ozone-based p-type doping.

The repository includes the final report, final presentation, outline, and selected report figures. The large raw measurement archive is excluded; only curated result data should be added later if needed.
